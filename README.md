# Mini-REPL Evaluador Postfijo (RPN)

Un entorno interactivo de consola (REPL) desarrollado en **Nim** que evalúa expresiones matemáticas y lógicas utilizando Notación Polaca Inversa (RPN) basada en una pila. 

Este proyecto fue desarrollado como parte de la Asignación #1 para la asignatura de Lenguajes de Programación, demostrando conceptos de sistemas de tipos, manejo de errores, mutabilidad y entornos de alcance local (scoping).
